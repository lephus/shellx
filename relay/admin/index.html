Đang tải

Admin chưa được bật

Trên VPS, đặt ADMIN_PASSWORD (≥ 16 ký tự) trong ~/phu/shellx/.env rồi chạy lại relay:

cd ~/phu/shellx
echo "ADMIN_PASSWORD=$(openssl rand -hex 24)" >> .env
docker compose up -d relay

Mật khẩu nằm trong .env (xem: grep ADMIN_PASSWORD .env). Đừng gửi nó qua chat.
