# ShellX v1.0 — Plan 02: `shellx_core` và gốc Dart workspace — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tạo gốc Dart pub workspace và package Dart thuần `packages/shellx_core` cung cấp **đúng** mọi API trong overview §5.1–§5.5 (khung relay, Noise IK/IKpsk2, payload kênh, tin nhắn CBOR, URI ghép nối, định danh thiết bị, client REST, kết nối relay tự nối lại) và khớp byte-for-byte định dạng dây overview §4.1–§4.2.

**Architecture:** Mọi cài đặt nằm trong `packages/shellx_core/lib/src/…` và được export qua duy nhất `lib/shellx_core.dart`. Noise được cài theo Noise spec rev 34 cho đúng hai pattern IK/IKpsk2: X25519 và ChaCha20-Poly1305 lấy từ `package:cryptography`, còn BLAKE2s/HMAC/HKDF chạy đồng bộ (HMAC tự cài vì HMAC của thư viện sai block size). CBOR đi qua một helper nội bộ dùng API nâng cao của `package:cbor` để kiểm soát chính xác kiểu trên dây (`data` luôn là byte string). `RelayConnection` chỉ phụ thuộc interface `RelaySocket` nên được test hoàn toàn bằng socket giả + `fake_async`; `ShellxApi` được test bằng `MockClient`.

**Tech Stack:** Dart 3.11.5 (SDK của Flutter 3.41.7), pub workspaces (`resolution: workspace`); `cryptography` 2.9.0, `cbor` 6.5.1, `http` 1.6.0; dev: `test` ^1.30.0, `fake_async` ^1.3.3, `lints` ^6.0.0.

**Spec:** `docs/superpowers/specs/2026-09-25-shellx-v1-design.md` — **Hợp đồng bắt buộc:** `docs/superpowers/plans/2026-09-25-shellx-v1-00-overview.md` (§2, §3, §4.1–§4.3, §5.1–§5.5). Relay TypeScript (plan 01) được viết độc lập từ cùng hợp đồng, nên mọi định dạng dây ở đây phải khớp từng byte.

## Global Constraints

Toàn bộ overview §2 áp dụng cho mọi task. Giá trị riêng của plan này (nguyên văn từ spec/overview):

- Gốc workspace: `pubspec.yaml` và `analysis_options.yaml` **đúng như overview §3** (sao lại nguyên văn ở Task 1). `packages/shellx_core/pubspec.yaml` có `resolution: workspace`. Dart SDK `^3.11.0`.
- Khung relay (overview §4.1): `Byte 0 : version = 1`; `0x01 DATA [2..17] peer device_id (UUID, 16 byte, big-endian như chuỗi hex) [18..25] channel_id (8 byte) [26..] payload`; `0x02 PRESENCE [2..17] device_id | [18] 0 = offline, 1 = online`; `0x03 ERROR [2..3] code (uint16 big-endian) | [4..19] device_id | [20..27] channel_id`; `0x04 EVENT [2..] CBOR map, khóa và giá trị đều là text string`. "ERROR không gắn với peer dùng `device_id` = UUID nil và `channel_id` = 8 byte 0."
- Mã lỗi: `1 peer_offline`, `2 frame_too_large`, `3 rate_limited`, `4 bad_frame`. Mã đóng WebSocket: **4001 replaced**, **4002 revoked**, **4003 rate_limited**.
- "Khung WebSocket tối đa **64 KiB**" — plan này hiểu là cả message nhị phân kể cả header (`kMaxFrameBytes = 65536`).
- Payload kênh (overview §4.2): `Byte 0 : kind — 0x01 HS1_IK | 0x02 HS1_IKPSK2 | 0x03 HS2 | 0x04 TRANSPORT`, `Byte 1.. : Noise message`.
- Noise: `Noise_IK_25519_ChaChaPoly_BLAKE2s` (kết nối thường) và `Noise_IKpsk2_25519_ChaChaPoly_BLAKE2s` (ghép nối). "Mobile là initiator, agent là responder." "Noise được cài đặt trong `shellx_core` bằng package `cryptography` và phải vượt qua bộ test vector chính thức của Noise cho hai pattern trên."
- "Prologue = UTF-8 `"shellx/1"` ‖ 16 byte UUID agent ‖ 16 byte UUID mobile."
- "Payload HS1 (CBOR): `{proto: 1, app: "<phiên bản app>", name: "<tên thiết bị>", platform}`." "Payload HS2 (CBOR): `{proto: 1, app, status}` với `status ∈ {"ok", "untrusted", "pairing_invalid", "proto_unsupported"}`."
- "Payload của mỗi TRANSPORT là **mảng CBOR gồm 1..n tin nhắn**. Mỗi tin nhắn là map CBOR có khóa `t`." Khóa CBOR: `"t"` + snake_case (`id, index, shell, created_at, attached, sessions, cols, rows, last_seq, seq, data (byte string), exit_code, reason, code, message`). "Mỗi tin `output` tối đa **16 KiB**."
- Nhịp tim: "client gửi văn bản `ping` mỗi **30 s**; không nhận `pong` trong **10 s** thì coi là mất kết nối." Kết nối lại: "thời gian chờ tăng dần **1 s → tối đa 30 s**, có độ trễ ngẫu nhiên"; công thức overview: `base = min(max, initial * 2^attempt); trả base/2 + random(0..base/2)`. "Đóng với 4002 → revoked, 4001 → replaced: KHÔNG tự kết nối lại. Mã khác → kết nối lại theo Backoff."
- WebSocket: `wss://relay.shellx.pro/v1/ws`, header `Authorization: Bearer <token>`. REST (spec §10.2, overview §4.3, gồm cả `DELETE /v1/account {password}` → `204` / `401 invalid_credentials`): "Lỗi luôn là `{"error": {"code": "<snake_case>", "message": "<text>"}}`. Timestamp trong JSON là số nguyên unix **mili giây** (hoặc `null`)." `device = {kind: "agent" | "mobile", name, platform: "macos" | "windows" | "ios" | "android", public_key}` với `public_key` là base64url 32 byte. `ApiException`: "status 0 + code "network" khi lỗi mạng".
- QR: `shellx://pair?v=1&d=<agent_device_id>&k=<agent_public_key_b64url>&s=<pairing_secret_b64url>`; "Mã ghép nối: **32 byte**".
- `DeviceIdentity.storageKey = 'device_private_key'` (base64url khóa bí mật).
- "Không bao giờ ghi log payload, token hay mật khẩu." → `toString()` của tin nhắn không in byte; `ApiException` không chứa token.
- **Ràng buộc phiên bản (đã kiểm tra trên máy này):** Flutter 3.41.7 ghim `test_api 0.7.10`, `fake_async 1.3.3`, `meta 1.17.0`, `collection 1.19.1`. ### Sự thật về thư viện đã kiểm chứng (đọc mã nguồn trong `~/.pub-cache` và chạy thử)

- **`cryptography` 2.9.0** (`package:cryptography/cryptography.dart`): `X25519()` → `newKeyPair()`, `newKeyPairFromSeed(List<int> seed)` (seed được clamp khi lưu), `extractPrivateKeyBytes()`, `extractPublicKey()` → `SimplePublicKey(.bytes)`; `sharedSecretKey({required KeyPair keyPair, required PublicKey remotePublicKey})` → `SecretKey.extractBytes()`; `SimpleKeyPairData(bytes, publicKey: SimplePublicKey(bytes, type: KeyPairType.x25519), type: KeyPairType.x25519)`. `Chacha20.poly1305Aead()` → `encrypt(clearText, secretKey: SecretKey(k), nonce: n, aad: ad)` trả `SecretBox(cipherText, nonce:, mac: Mac(bytes))`; `decrypt(SecretBox, secretKey:, aad:)` ném `SecretBoxAuthenticationError`. BLAKE2s đồng bộ: `DartBlake2s().hashSync(data).bytes` (`package:cryptography/dart.dart`).
- **Bẫy đã xác minh:** trong 2.9.0 `Blake2s.blockLengthInBytes == 32`, nên `Hmac.blake2s()` **không** phải HMAC-BLAKE2s chuẩn RFC 2104 (cần block 64 byte). Với key `"key"`, message `"The quick brown fox jumps over the lazy dog"`: chuẩn (Python `hmac.new(key, msg, hashlib.blake2s)`) = `f93215bb90d4af4c3061cd932fb169fb8bb8a91d0b4022baea1271e1323cd9a0`, còn `Hmac.blake2s()` = `7302e4c3cf37d3183b10b4645d74990cf45148233eb3c3525f1ff1360e5c8c13`. Plan tự cài HMAC với BLOCKLEN = 64 (Task 3) và có test khóa lại sự khác biệt này.
- `package:cryptography` export một class tên `CipherState` → CipherState/SymmetricState của Noise đặt tên `NoiseCipherState`/`NoiseSymmetricState` (nội bộ, không export).
- **`cbor` 6.5.1** (`package:cbor/cbor.dart`; **không** import `package:cbor/simple.dart` vì nó định nghĩa một `cbor` khác): `cbor.encode(CborValue) → List<int>`, `cbor.decode(List<int>) → CborValue`; `CborMap({...})`, `CborList([...])`, `CborString(s)` (`toString()`), `CborSmallInt(i)`, `CborInt.toInt()`, `CborBytes(bytes)` (`.bytes`), `CborBool(b)` (`.value`), `CborNull()`. Input rỗng/thiếu/thừa ném `FormatException`; byte hỏng ném `CborMalformedException extends FormatException`.
- **`http` 1.6.0**: `MockClient((http.Request request) async => http.Response(body, status))` trong `package:http/testing.dart`; `request.headers` không phân biệt hoa thường; lỗi mạng là `http.ClientException(message)`; `http.Response(..., reasonPhrase: 'Bad Gateway')`.
- **`fake_async` 1.3.3**: `fakeAsync((FakeAsync async) { ...; async.elapse(duration); async.flushMicrotasks(); })`; `Future.timeout`, `Timer`, `Timer.periodic` bên trong đều dùng đồng hồ giả.
- **`dart:io`**: nâng cấp WebSocket bị từ chối ném `WebSocketException(message, httpStatusCode)`; `WebSocket.closeCode` có giá trị sau khi stream kết thúc.
- **Test vector Noise:** cacophony, commit `18b7348c54fd61fcd0c220298883de0d09c8364d`, `https://raw.githubusercontent.com/haskell-cryptography/cacophony/18b7348c54fd61fcd0c220298883de0d09c8364d/vectors/cacophony.txt` (1 709 817 byte, JSON `{"vectors": [...]}`, 944 vector). Trường đã kiểm tra: `protocol_name`, `init_prologue`, `init_static`, `init_ephemeral`, `init_remote_static`, `init_psks` (mảng; **chỉ có** ở vector psk), `resp_prologue`, `resp_static`, `resp_ephemeral`, `resp_psks` (**chỉ có** ở vector psk), `handshake_hash`, `messages[].payload`, `messages[].ciphertext` — tất cả là hex. Mỗi vector có 6 message: 0 initiator→responder, 1 responder→initiator, 2..5 transport luân phiên bắt đầu từ initiator. `init_static`/`init_ephemeral`/`resp_*` là khóa **bí mật**; `init_remote_static` là khóa **công khai** của responder. (`snow.txt` của repo `mcginty/snow` không có `handshake_hash` và không có vector IKpsk2 nên không dùng.)

## Review Focus

Overview §6: không dòng nào thuộc plan 02 (dòng 1–4 thuộc plan 03/05, dòng 5 thuộc plan 01). Năm tình huống spec ngụ ý mà plan này sở hữu, xếp theo khả năng gây lỗi cho người dùng — mỗi dòng có test ở task sở hữu:

2. **Relay phát lại/đảo thứ tự/sửa ciphertext, tráo `device_id` (prologue), hoặc QR sai mã** — người dùng mong không bao giờ nhận dữ liệu giả, mà kênh báo lỗi để bắt tay lại. Test: Task 4 `replayed, reordered and tampered messages are rejected`, `prologue mismatch (swapped device ids) fails on message 1`, `wrong pairing secret: responder reads message 1, initiator cannot read message 2`.
3. **Sự kiện muộn từ socket cũ sau khi đã tự kết nối lại** (ví dụ 4001 tới trên socket bị bỏ vì hết hạn `pong`), **hoặc lần kết nối bị treo** — người dùng mong app không tự nhận "bị thay thế" và không kẹt ở "đang kết nối". Test: Task 11 `events from an abandoned socket are ignored (late 4001 after pong timeout)`, `a connect attempt that hangs is abandoned after 15 s`.
4. **Relay/proxy trả trang HTML lỗi, 429 không có JSON, hoặc không bao giờ trả lời** — người dùng mong thông báo lỗi đúng (vẫn giữ status 429 để UI hiện "Thử lại sau ít phút.") chứ không crash hay quay mãi. Test: Task 9 `non-JSON error bodies (proxy pages) become http_<status>`, `429 without a JSON body keeps status 429`, `a request that never answers times out after 20 s as "network"`.
5. **Lần chạy đầu hai thành phần cùng gọi `DeviceIdentity.loadOrCreate`, hoặc khóa lưu bị hỏng** — người dùng mong đúng một khóa thiết bị (nếu sinh hai khóa, ghép nối vừa làm sẽ mất), không crash. Test: Task 8 `concurrent first calls generate a single key`, `replaces a corrupted stored key instead of crashing`.

```dart
final RegExp _uuidPattern = RegExp(
  r'^[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}$',

final RegExp _hexPattern = RegExp(r'^(?:[0-9a-fA-F]{2})*$');

/// Parses a `8-4-4-4-12` UUID string (any case) into its 16 raw bytes.
///
/// Throws [FormatException] if [uuid] is not a well-formed UUID.
Uint8List uuidToBytes(String uuid) {
  if (!_uuidPattern.hasMatch(uuid)) {
    throw FormatException('Invalid UUID', uuid);
  }
  return hexToBytes(uuid.replaceAll('-', ''));
}

/// Formats 16 raw bytes as a lowercase `8-4-4-4-12` UUID string.
///
/// Throws [ArgumentError] if [bytes] is not exactly 16 bytes long.
String uuidFromBytes(Uint8List bytes) {
  if (bytes.length != 16) {
    throw ArgumentError.value(bytes.length, 'bytes', 'UUID must be 16 bytes');
  }
  final hex = bytesToHex(bytes);
  return '${hex.substring(0, 8)}-${hex.substring(8, 12)}-'
      '${hex.substring(12, 16)}-${hex.substring(16, 20)}-${hex.substring(20)}';
}

/// Encodes [bytes] as base64url without `=` padding.
String base64UrlNoPad(Uint8List bytes) =>
    base64Url.encode(bytes).replaceAll('=', '');

/// Decodes base64url text. Trailing `=` padding is tolerated but not required.
///
/// Throws [FormatException] for characters outside the base64url alphabet
/// (including `+` and `/`) or for an impossible length.
Uint8List fromBase64UrlNoPad(String input) {
  var body = input;
  while (body.endsWith('=')) {
    body = body.substring(0, body.length - 1);
  }
  if (!_base64UrlPattern.hasMatch(body) || body.length % 4 == 1) {
    throw FormatException('Invalid base64url', input);
  }
  final padded = body.padRight((body.length + 3) ~/ 4 * 4, '=');
  return base64Url.decode(padded);
}

/// Compares two byte arrays in time that depends only on their lengths.
bool constantTimeEquals(Uint8List a, Uint8List b) {
  if (a.length != b.length) {
    return false;
  }
  var diff = 0;
  for (var i = 0; i < a.length; i++) {
    diff |= a[i] ^ b[i];
  }
  return diff == 0;
}

/// Lowercase hexadecimal representation of [bytes].
String bytesToHex(List<int> bytes) {
  final buffer = StringBuffer();
  for (final byte in bytes) {
    buffer.write(byte.toRadixString(16).padLeft(2, '0'));
  }
  return buffer.toString();
}

Uint8List hexToBytes(String hex) {
  if (!_hexPattern.hasMatch(hex)) {
    throw FormatException('Invalid hex', hex);
  }
  final out = Uint8List(hex.length ~/ 2);
  for (var i = 0; i < out.length; i++) {
    out[i] = int.parse(hex.substring(i * 2, i * 2 + 2), radix: 16);
  }
  return out;
}

  final builder = BytesBuilder(copy: false);
  for (final chunk in chunks) {
    builder.add(chunk);
  }
  return builder.takeBytes();
```

```dart
import 'dart:typed_data';

import 'package:cbor/cbor.dart';

/// Encodes plain Dart values as CBOR.
///
/// Supported: `null`, [bool], [int], [String], [Uint8List] (byte string),
/// [List] (array) and [Map] (map). Anything else throws [ArgumentError].
Uint8List encodeCbor(Object? value) =>
    Uint8List.fromList(cbor.encode(_toCborValue(value)));

/// Decodes a single CBOR item into plain Dart values.
///
/// Byte strings become [Uint8List], arrays become `List<Object?>`, maps
/// become `Map<Object?, Object?>`, integers become [int].
/// Throws [FormatException] for malformed input or unsupported item types.
Object? decodeCbor(Uint8List bytes) {
  final CborValue value;
  try {
    value = cbor.decode(bytes);
  } on FormatException {
    rethrow;
  } on Object catch (error) {
    throw FormatException('Malformed CBOR: $error');
  }
  return _fromCborValue(value);
}

CborValue _toCborValue(Object? value) {
  return switch (value) {
    null => const CborNull(),
    bool b => CborBool(b),
    int i => CborSmallInt(i),
    String s => CborString(s),
    Uint8List b => CborBytes(b),
    List<Object?> list => CborList([
      for (final item in list) _toCborValue(item),
    ]),
    Map<Object?, Object?> map => CborMap({
      for (final entry in map.entries)
        _toCborValue(entry.key): _toCborValue(entry.value),
    }),
    _ => throw ArgumentError.value(value, 'value', 'Unsupported CBOR type'),
  };
}

Object? _fromCborValue(CborValue value) {
  return switch (value) {
    CborNull() => null,
    CborBool(:final value) => value,
    CborInt() => value.toInt(),
    CborString() => value.toString(),
    CborBytes(:final bytes) => Uint8List.fromList(bytes),
    CborList() => <Object?>[for (final item in value) _fromCborValue(item)],
    CborMap() => <Object?, Object?>{
      for (final entry in value.entries)
        _fromCborValue(entry.key): _fromCborValue(entry.value),
    },
    _ => throw FormatException('Unsupported CBOR item: ${value.runtimeType}'),
  };
}
```

```dart
/// 8-byte identifier of one Noise channel between a mobile and an agent.
final class ChannelId {
  /// Throws [ArgumentError] if [bytes] is not exactly 8 bytes long.
  ChannelId(Uint8List bytes) : bytes = _checked(bytes);

  /// A fresh random id. Uses [Random.secure] unless [random] is given.
  factory ChannelId.random([Random? random]) {
    final source = random ?? Random.secure();
    return ChannelId(
      Uint8List.fromList(List<int>.generate(8, (_) => source.nextInt(256))),
    );
  }

  /// All-zero id, used by relay ERROR frames that are not tied to a channel.
  static final ChannelId zero = ChannelId(Uint8List(8));

  final Uint8List bytes;

  static Uint8List _checked(Uint8List bytes) {
    if (bytes.length != 8) {
      throw ArgumentError.value(
        bytes.length,
        'bytes',
        'ChannelId must be 8 bytes',
      );
    }
    return Uint8List.fromList(bytes);
  }

  @override
  bool operator ==(Object other) =>
      other is ChannelId && constantTimeEquals(bytes, other.bytes);

  @override
  int get hashCode => Object.hashAll(bytes);

  @override
  String toString() => bytesToHex(bytes);
```

```dart
import 'dart:typed_data';

import '../util/bytes.dart';
import '../util/cbor_values.dart';
import 'channel_id.dart';

const int kRelayProtocolVersion = 1;
const int kMaxFrameBytes = 64 * 1024;

/// Number of header bytes in front of a DATA frame payload.
const int kDataFrameHeaderBytes = 26;

const int _typeData = 0x01;
const int _typePresence = 0x02;
const int _typeError = 0x03;
const int _typeEvent = 0x04;

abstract final class RelayCloseCode {
  static const int replaced = 4001;
  static const int revoked = 4002;
  static const int rateLimited = 4003;
}

enum RelayErrorCode {
  peerOffline(1),
  frameTooLarge(2),
  rateLimited(3),
  badFrame(4);

  const RelayErrorCode(this.wire);
  final int wire;

  /// Throws [FrameFormatException] for an unknown code.
  static RelayErrorCode fromWire(int wire) {
    for (final code in values) {
      if (code.wire == wire) {
        return code;
      }
    }
    throw FrameFormatException('Unknown relay error code $wire');
  }
}

final class FrameFormatException implements Exception {
  const FrameFormatException(this.message);
  final String message;

  @override
  String toString() => 'FrameFormatException: $message';
}

/// A binary WebSocket frame exchanged with the relay hub (spec section 6.2).
sealed class RelayFrame {
  const RelayFrame();

  Uint8List encode();

  /// Parses one binary frame. Throws [FrameFormatException] if the frame is
  /// truncated, has the wrong version, has an unknown type or bad fields.
  static RelayFrame decode(Uint8List bytes) {
    if (bytes.length < 2) {
      throw const FrameFormatException('Frame shorter than 2 bytes');
    }
    if (bytes[0] != kRelayProtocolVersion) {
      throw FrameFormatException('Unsupported frame version ${bytes[0]}');
    }
    switch (bytes[1]) {
      case _typeData:
        if (bytes.length < kDataFrameHeaderBytes) {
          throw const FrameFormatException('DATA frame too short');
        }
        return DataFrame(
          peer: uuidFromBytes(Uint8List.sublistView(bytes, 2, 18)),
          channel: ChannelId(Uint8List.sublistView(bytes, 18, 26)),
          payload: Uint8List.fromList(Uint8List.sublistView(bytes, 26)),
        );
      case _typePresence:
        if (bytes.length != 19) {
          throw const FrameFormatException('PRESENCE frame must be 19 bytes');
        }
        final flag = bytes[18];
        if (flag > 1) {
          throw FrameFormatException('Bad PRESENCE flag $flag');
        }
        return PresenceFrame(
          deviceId: uuidFromBytes(Uint8List.sublistView(bytes, 2, 18)),
          online: flag == 1,
        );
      case _typeError:
        if (bytes.length != 28) {
          throw const FrameFormatException('ERROR frame must be 28 bytes');
        }
        return ErrorFrame(
          code: RelayErrorCode.fromWire((bytes[2] << 8) | bytes[3]),
          deviceId: uuidFromBytes(Uint8List.sublistView(bytes, 4, 20)),
          channel: ChannelId(Uint8List.sublistView(bytes, 20, 28)),
        );
      case _typeEvent:
        return EventFrame(_decodeEvent(Uint8List.sublistView(bytes, 2)));
      default:
        throw FrameFormatException('Unknown frame type ${bytes[1]}');
    }
  }

  static Map<String, String> _decodeEvent(Uint8List body) {
    final Object? decoded;
    try {
      decoded = decodeCbor(body);
    } on FormatException catch (error) {
      throw FrameFormatException('Bad EVENT CBOR: ${error.message}');
    }
    if (decoded is! Map) {
      throw const FrameFormatException('EVENT body must be a CBOR map');
    }
    final event = <String, String>{};
    for (final entry in decoded.entries) {
      final key = entry.key;
      final value = entry.value;
      if (key is! String || value is! String) {
        throw const FrameFormatException('EVENT keys and values must be text');
      }
      event[key] = value;
    }
    return event;
  }
}

final class DataFrame extends RelayFrame {
  DataFrame({required this.peer, required this.channel, required this.payload});

  /// Upstream: destination device. Downstream: source device.
  final String peer;
  final ChannelId channel;
  final Uint8List payload;

  @override
  Uint8List encode() => concatBytes([
    [kRelayProtocolVersion, _typeData],
    uuidToBytes(peer),
    channel.bytes,
    payload,
  ]);

  @override
  bool operator ==(Object other) =>
      other is DataFrame &&
      other.peer == peer &&
      other.channel == channel &&
      constantTimeEquals(other.payload, payload);

  @override
  int get hashCode => Object.hash(peer, channel, Object.hashAll(payload));

  @override
  String toString() =>
      'DataFrame(peer: $peer, channel: $channel, ${payload.length} bytes)';
}

final class PresenceFrame extends RelayFrame {
  const PresenceFrame({required this.deviceId, required this.online});

  final String deviceId;
  final bool online;

  @override

      other is PresenceFrame &&
      other.deviceId == deviceId &&
      other.online == online;

  @override

  @override

final class ErrorFrame extends RelayFrame {
  ErrorFrame({required this.code, this.deviceId = nilUuid, ChannelId? channel})
    : channel = channel ?? ChannelId.zero;

  final RelayErrorCode code;
  final String deviceId;
  final ChannelId channel;

    [kRelayProtocolVersion, _typeError, code.wire >> 8, code.wire & 0xff],

    channel.bytes,
  ]);

  @override
  bool operator ==(Object other) =>
      other is ErrorFrame &&
      other.code == code &&
      other.deviceId == deviceId &&
      other.channel == channel;

  @override

  @override

      'ErrorFrame(code: ${code.name}, deviceId: $deviceId, channel: $channel)';

final class EventFrame extends RelayFrame {
  const EventFrame(this.event);

  /// For example `{"event": "pairing_removed", "agent_id": ..., "mobile_id": ...}`.
  final Map<String, String> event;

  @override
  Uint8List encode() => concatBytes([
    [kRelayProtocolVersion, _typeEvent],
    encodeCbor(event),
  ]);

  @override
  bool operator ==(Object other) {
    if (other is! EventFrame || other.event.length != event.length) {
      return false;
    }
    for (final entry in event.entries) {
      if (other.event[entry.key] != entry.value) {
        return false;
      }
    }
    return true;
  }

  @override
  int get hashCode => Object.hashAllUnordered(
    event.entries.map((entry) => Object.hash(entry.key, entry.value)),
  );

  @override
  String toString() => 'EventFrame($event)';
}
```

```dart
// Noise crypto functions for 25519 / ChaChaPoly / BLAKE2s (Noise rev 34, §4).
//
// HMAC is implemented here on purpose: in package:cryptography 2.9.0
// `Blake2s.blockLengthInBytes` is 32, so `Hmac.blake2s()` is not RFC 2104
// HMAC-BLAKE2s (which needs the 64-byte BLAKE2s block). Noise needs the
// RFC 2104 construction with BLOCKLEN = 64.
import 'dart:typed_data';

import 'package:cryptography/cryptography.dart';
import 'package:cryptography/dart.dart';

import '../util/bytes.dart';
import 'noise_key_pair.dart';

const int dhLen = 32;
const int hashLen = 32;
const int blockLen = 64;
const int tagLen = 16;

final X25519 _x25519 = X25519();
final Cipher _chachaPoly = Chacha20.poly1305Aead();
final DartBlake2s _blake2s = DartBlake2s();

/// BLAKE2s-256 of [data].
Uint8List noiseHash(List<int> data) =>
    Uint8List.fromList(_blake2s.hashSync(data).bytes);

/// RFC 2104 HMAC with BLAKE2s and a 64-byte block.
Uint8List hmacBlake2s(List<int> key, List<int> data) {
  final normalizedKey = key.length > blockLen ? noiseHash(key) : key;
  final ipad = Uint8List(blockLen);
  final opad = Uint8List(blockLen);
  for (var i = 0; i < blockLen; i++) {
    final k = i < normalizedKey.length ? normalizedKey[i] : 0;
    ipad[i] = k ^ 0x36;
    opad[i] = k ^ 0x5c;
  }
  final inner = noiseHash(concatBytes([ipad, data]));
  return noiseHash(concatBytes([opad, inner]));
}

/// Noise HKDF returning 2 or 3 outputs of [hashLen] bytes.
List<Uint8List> hkdf(
  Uint8List chainingKey,
  List<int> inputKeyMaterial,
  int numOutputs,
) {
  if (numOutputs != 2 && numOutputs != 3) {
    throw ArgumentError.value(numOutputs, 'numOutputs', 'must be 2 or 3');
  }
  final tempKey = hmacBlake2s(chainingKey, inputKeyMaterial);
  final output1 = hmacBlake2s(tempKey, [0x01]);
  final output2 = hmacBlake2s(
    tempKey,
    concatBytes([
      output1,
      [0x02],
    ]),
  );
  if (numOutputs == 2) {
    return [output1, output2];
  }
  final output3 = hmacBlake2s(
    tempKey,
    concatBytes([
      output2,
      [0x03],
    ]),
  );
  return [output1, output2, output3];
}

/// X25519 DH. Throws [NoiseException] if the result is all zeros
/// (low-order public key).
Future<Uint8List> dh(NoiseKeyPair keyPair, Uint8List publicKey) async {
  if (publicKey.length != dhLen) {
    throw const NoiseException('Public key must be 32 bytes');
  }
  final secret = await _x25519.sharedSecretKey(
    keyPair: SimpleKeyPairData(
      keyPair.privateKey,
      publicKey: SimplePublicKey(keyPair.publicKey, type: KeyPairType.x25519),
      type: KeyPairType.x25519,
    ),
    remotePublicKey: SimplePublicKey(publicKey, type: KeyPairType.x25519),
  );
  final bytes = Uint8List.fromList(await secret.extractBytes());
  if (constantTimeEquals(bytes, Uint8List(dhLen))) {
    throw const NoiseException('Invalid DH public key');
  }
  return bytes;
}

/// ChaChaPoly nonce: 4 zero bytes followed by the 64-bit little-endian counter.
Uint8List noiseNonce(int n) {
  final nonce = Uint8List(12);
  ByteData.sublistView(nonce).setUint64(4, n, Endian.little);
  return nonce;
}

/// ChaCha20-Poly1305 encryption; returns ciphertext || 16-byte tag.
Future<Uint8List> aeadEncrypt(
  Uint8List key,
  int n,
  List<int> ad,
  List<int> plaintext,
) async {
  final box = await _chachaPoly.encrypt(
    plaintext,
    secretKey: SecretKey(key),
    nonce: noiseNonce(n),
    aad: ad,
  );
  return concatBytes([box.cipherText, box.mac.bytes]);
}

/// ChaCha20-Poly1305 decryption of ciphertext || tag.
/// Throws [NoiseException] on authentication failure.
Future<Uint8List> aeadDecrypt(
  Uint8List key,
  int n,
  List<int> ad,
  Uint8List ciphertext,
) async {
  if (ciphertext.length < tagLen) {
    throw const NoiseException('Ciphertext shorter than the tag');
  }
  final split = ciphertext.length - tagLen;
  final box = SecretBox(
    Uint8List.sublistView(ciphertext, 0, split),
    nonce: noiseNonce(n),
    mac: Mac(Uint8List.sublistView(ciphertext, split)),
  );
  try {
    final plaintext = await _chachaPoly.decrypt(
      box,
      secretKey: SecretKey(key),
      aad: ad,
    );
    return Uint8List.fromList(plaintext);
  } on SecretBoxAuthenticationError {
    throw const NoiseException('Decryption failed');
  }
}
```

```dart
// CipherState and SymmetricState (as NoiseCipherState / NoiseSymmetricState) from the Noise spec rev 34, §5.1 and §5.2.
import 'dart:convert';
import 'dart:typed_data';

import '../util/bytes.dart';
import 'noise_key_pair.dart';
import 'primitives.dart';

/// Largest nonce we will use. Noise reserves 2^64-1; Dart ints are signed
/// 64-bit, so we stop at 2^63-1, which is never reached in practice.
const int _maxNonce = 0x7fffffffffffffff;

final class NoiseCipherState {
  Uint8List? _k;
  int _n = 0;

  bool get hasKey => _k != null;

  /// Current nonce (exposed for tests).
  int get nonce => _n;

  void initializeKey(Uint8List? key) {
    _k = key == null ? null : Uint8List.fromList(key);
    _n = 0;
  }

  /// Encrypts with the current nonce, then increments it. Without a key the
  /// plaintext is returned unchanged (Noise §5.1).
  Future<Uint8List> encryptWithAd(List<int> ad, List<int> plaintext) {
    final k = _k;
    if (k == null) {
      return Future.value(Uint8List.fromList(plaintext));
    }
    if (_n >= _maxNonce) {
      throw const NoiseException('Nonce exhausted');
    }
    final n = _n++;
    return aeadEncrypt(k, n, ad, plaintext);
  }

  /// Decrypts with the current nonce. The nonce is incremented only on
  /// success. Throws [NoiseException] on authentication failure.
  Future<Uint8List> decryptWithAd(List<int> ad, Uint8List ciphertext) async {
    final k = _k;
    if (k == null) {
      return Uint8List.fromList(ciphertext);
    }
    if (_n >= _maxNonce) {
      throw const NoiseException('Nonce exhausted');
    }
    final plaintext = await aeadDecrypt(k, _n, ad, ciphertext);
    _n++;
    return plaintext;
  }
}

final class NoiseSymmetricState {
  NoiseSymmetricState(String protocolName) {
    final name = utf8.encode(protocolName);
    if (name.length <= hashLen) {
      _h = Uint8List(hashLen)..setAll(0, name);
    } else {
      _h = noiseHash(name);
    }
    _ck = Uint8List.fromList(_h);
  }

  late Uint8List _ck;
  late Uint8List _h;
  final NoiseCipherState cipher = NoiseCipherState();

  Uint8List get chainingKey => Uint8List.fromList(_ck);
  Uint8List get handshakeHash => Uint8List.fromList(_h);

  void mixKey(List<int> inputKeyMaterial) {
    final outputs = hkdf(_ck, inputKeyMaterial, 2);
    _ck = outputs[0];
    cipher.initializeKey(outputs[1]);
  }

  void mixHash(List<int> data) {
    _h = noiseHash(concatBytes([_h, data]));
  }

  void mixKeyAndHash(List<int> inputKeyMaterial) {
    final outputs = hkdf(_ck, inputKeyMaterial, 3);
    _ck = outputs[0];
    mixHash(outputs[1]);
    cipher.initializeKey(outputs[2]);
  }

  Future<Uint8List> encryptAndHash(List<int> plaintext) async {
    final ciphertext = await cipher.encryptWithAd(_h, plaintext);
    mixHash(ciphertext);
    return ciphertext;
  }

  Future<Uint8List> decryptAndHash(Uint8List ciphertext) async {
    final plaintext = await cipher.decryptWithAd(_h, ciphertext);
    mixHash(ciphertext);
    return plaintext;
  }

  /// Returns the two transport cipher states (initiator→responder first).
  (NoiseCipherState, NoiseCipherState) split() {
    final outputs = hkdf(_ck, const <int>[], 2);
    return (
      NoiseCipherState()..initializeKey(outputs[0]),
      NoiseCipherState()..initializeKey(outputs[1]),
    );
  }
}
```

```dart
// HandshakeState (Noise rev 34, §5.3) for exactly two patterns:
//
//   IK:                        IKpsk2:
//     <- s                       <- s
//     ...                        ...
//     -> e, es, s, ss            -> e, es, s, ss
//     <- e, ee, se               <- e, ee, se, psk
//
// In psk mode every `e` token also calls MixKey(e.public_key) (§9.2).
import 'dart:typed_data';

import 'noise_key_pair.dart';
import 'primitives.dart';
import 'symmetric_state.dart';

enum NoisePattern {
  ik('Noise_IK_25519_ChaChaPoly_BLAKE2s'),
  ikPsk2('Noise_IKpsk2_25519_ChaChaPoly_BLAKE2s');

  const NoisePattern(this.protocolName);
  final String protocolName;
}

final class NoiseHandshake {
  NoiseHandshake.initiator({
    required NoisePattern pattern,
    required NoiseKeyPair localStatic,
    required Uint8List remoteStatic,
    required Uint8List prologue,
    Uint8List? psk,
    NoiseKeyPair? ephemeral,
  }) : _pattern = pattern,
       _initiator = true,
       _s = localStatic,
       _rs = _checkedKey(remoteStatic, 'remoteStatic'),
       _psk = _checkedPsk(pattern, psk),
       _presetEphemeral = ephemeral,
       _symmetric = NoiseSymmetricState(pattern.protocolName) {
    _symmetric.mixHash(prologue);
    _symmetric.mixHash(remoteStatic); // pre-message "<- s"
  }

  NoiseHandshake.responder({
    required NoisePattern pattern,
    required NoiseKeyPair localStatic,
    required Uint8List prologue,
    Uint8List? psk,
    NoiseKeyPair? ephemeral,
  }) : _pattern = pattern,
       _initiator = false,
       _s = localStatic,
       _psk = _checkedPsk(pattern, psk),
       _presetEphemeral = ephemeral,
       _symmetric = NoiseSymmetricState(pattern.protocolName) {
    _symmetric.mixHash(prologue);
    _symmetric.mixHash(localStatic.publicKey); // pre-message "<- s"
  }

  final NoisePattern _pattern;
  final bool _initiator;
  final NoiseKeyPair _s;
  final Uint8List? _psk;
  final NoiseKeyPair? _presetEphemeral;
  final NoiseSymmetricState _symmetric;
  Uint8List? _rs;
  NoiseKeyPair? _e;
  Uint8List? _re;

  /// 0 = before message 1, 1 = before message 2, 2 = complete.
  int _messageIndex = 0;
  bool _busy = false;
  bool _failed = false;

  bool get _pskMode => _pattern == NoisePattern.ikPsk2;

  bool get isComplete => _messageIndex == 2;

  /// Initiator: the key given to the constructor. Responder: set after
  /// reading message 1.
  Uint8List? get remoteStatic => _rs == null ? null : Uint8List.fromList(_rs!);

  Uint8List get handshakeHash => _symmetric.handshakeHash;

  /// Writes the next handshake message. Fails with [StateError] when it is
  /// not this side's turn or the handshake already failed.
  Future<Uint8List> writeMessage([Uint8List? payload]) async {
    _checkUsable();
    final ourTurn = _initiator ? _messageIndex == 0 : _messageIndex == 1;
    if (!ourTurn) {
      throw StateError('Not our turn to write');
    }
    final body = payload ?? Uint8List(0);
    return _run(() => _initiator ? _writeMessage1(body) : _writeMessage2(body));
  }

  /// Reads the next handshake message and returns its decrypted payload.
  /// Fails with [NoiseException] for truncated or unauthentic messages
  /// (after which the handshake is unusable) and with [StateError] when it
  /// is not this side's turn.
  Future<Uint8List> readMessage(Uint8List message) async {
    _checkUsable();
    final ourTurn = _initiator ? _messageIndex == 1 : _messageIndex == 0;
    if (!ourTurn) {
      throw StateError('Not our turn to read');
    }
    return _run(
      () => _initiator ? _readMessage2(message) : _readMessage1(message),
    );
  }

  /// Derives the transport keys. Throws [StateError] before completion.
  NoiseTransport split() {
    if (!isComplete) {
      throw StateError('Handshake not complete');
    }
    final (c1, c2) = _symmetric.split();
    return _initiator ? NoiseTransport._(c1, c2) : NoiseTransport._(c2, c1);
  }

  void _checkUsable() {
    if (_failed) {
      throw StateError('Handshake already failed');
    }
    if (_busy) {
      throw StateError('Handshake step already in progress');
    }
  }

  Future<Uint8List> _run(Future<Uint8List> Function() step) async {
    _busy = true;
    try {
      final result = await step();
      _messageIndex++;
      return result;
    } catch (_) {
      _failed = true;
      rethrow;
    } finally {
      _busy = false;
    }
  }

  // -> e, es, s, ss
  Future<Uint8List> _writeMessage1(Uint8List payload) async {
    final e = await _ephemeral();
    final out = BytesBuilder(copy: false);
    _writeE(e, out);
    _symmetric.mixKey(await dh(e, _rs!)); // es
    out.add(await _symmetric.encryptAndHash(_s.publicKey)); // s
    _symmetric.mixKey(await dh(_s, _rs!)); // ss
    out.add(await _symmetric.encryptAndHash(payload));
    return out.takeBytes();
  }

  Future<Uint8List> _readMessage1(Uint8List message) async {
    const encryptedStaticLength = dhLen + tagLen;
    if (message.length < dhLen + encryptedStaticLength + tagLen) {
      throw const NoiseException('Handshake message 1 too short');
    }
    _readE(Uint8List.sublistView(message, 0, dhLen));
    _symmetric.mixKey(await dh(_s, _re!)); // es
    final rs = await _symmetric.decryptAndHash(
      Uint8List.sublistView(message, dhLen, dhLen + encryptedStaticLength),
    );
    _rs = rs; // s
    _symmetric.mixKey(await dh(_s, rs)); // ss
    return _symmetric.decryptAndHash(
      Uint8List.sublistView(message, dhLen + encryptedStaticLength),
    );
  }

  // <- e, ee, se [, psk]
  Future<Uint8List> _writeMessage2(Uint8List payload) async {
    final e = await _ephemeral();
    final out = BytesBuilder(copy: false);
    _writeE(e, out);
    _symmetric.mixKey(await dh(e, _re!)); // ee
    _symmetric.mixKey(await dh(e, _rs!)); // se
    if (_pskMode) {
      _symmetric.mixKeyAndHash(_psk!); // psk
    }
    out.add(await _symmetric.encryptAndHash(payload));
    return out.takeBytes();
  }

  Future<Uint8List> _readMessage2(Uint8List message) async {
    if (message.length < dhLen + tagLen) {
      throw const NoiseException('Handshake message 2 too short');
    }
    _readE(Uint8List.sublistView(message, 0, dhLen));
    _symmetric.mixKey(await dh(_e!, _re!)); // ee
    _symmetric.mixKey(await dh(_s, _re!)); // se
    if (_pskMode) {
      _symmetric.mixKeyAndHash(_psk!); // psk
    }
    return _symmetric.decryptAndHash(Uint8List.sublistView(message, dhLen));
  }

  Future<NoiseKeyPair> _ephemeral() async {
    final e = _presetEphemeral ?? await NoiseKeyPair.generate();
    _e = e;
    return e;
  }

  void _writeE(NoiseKeyPair e, BytesBuilder out) {
    out.add(e.publicKey);
    _symmetric.mixHash(e.publicKey);
    if (_pskMode) {
      _symmetric.mixKey(e.publicKey);
    }
  }

  void _readE(Uint8List re) {
    final copy = Uint8List.fromList(re);
    _re = copy;
    _symmetric.mixHash(copy);
    if (_pskMode) {
      _symmetric.mixKey(copy);
    }
  }

  static Uint8List _checkedKey(Uint8List key, String name) {
    if (key.length != dhLen) {
      throw ArgumentError.value(key.length, name, 'must be 32 bytes');
    }
    return Uint8List.fromList(key);
  }

  static Uint8List? _checkedPsk(NoisePattern pattern, Uint8List? psk) {
    if (pattern == NoisePattern.ik) {
      if (psk != null) {
        throw ArgumentError.value(psk, 'psk', 'must be null for Noise_IK');
      }
      return null;
    }
    if (psk == null || psk.length != 32) {
      throw ArgumentError.value(psk, 'psk', 'Noise_IKpsk2 needs a 32-byte psk');
    }
    return Uint8List.fromList(psk);
  }
}

/// Transport cipher pair produced by [NoiseHandshake.split].
///
/// Calls are serialized: each [encrypt] (and each [decrypt]) completes in the
/// order it was called, so nonces always match the order of the results.
final class NoiseTransport {
  NoiseTransport._(this._send, this._receive);

  /// Largest plaintext for one Noise transport message (65535 - 16).
  static const int maxPlaintextLength = 65535 - tagLen;

  final NoiseCipherState _send;
  final NoiseCipherState _receive;
  Future<void> _sendQueue = Future.value();
  Future<void> _receiveQueue = Future.value();

  Future<Uint8List> encrypt(Uint8List plaintext) {
    if (plaintext.length > maxPlaintextLength) {
      throw ArgumentError.value(
        plaintext.length,
        'plaintext',
        'exceeds $maxPlaintextLength bytes',
      );
    }
    final result = _sendQueue.then(
      (_) => _send.encryptWithAd(const <int>[], plaintext),
    );
    _sendQueue = result.then<void>((_) {}, onError: (Object _) {});
    return result;
  }

  /// Throws [NoiseException] if authentication fails (tampering, replay,
  /// reordering or a wrong key).
  Future<Uint8List> decrypt(Uint8List ciphertext) {
    final result = _receiveQueue.then(
      (_) => _receive.decryptWithAd(const <int>[], ciphertext),
    );
    _receiveQueue = result.then<void>((_) {}, onError: (Object _) {});
    return result;
  }
}
```

```dart
/// Throws [FormatException] if [bytes] is not a CBOR array of maps or a
/// known message is malformed.
List<AppMessage> decodeBatch(Uint8List bytes) {
  final decoded = decodeCbor(bytes);
  if (decoded is! List<Object?>) {
    throw const FormatException('Message batch must be a CBOR array');
  }
  final messages = <AppMessage>[];
  for (final item in decoded) {
    if (item is! Map<Object?, Object?>) {
      throw const FormatException('Batch item must be a CBOR map');
    }
    final message = AppMessage.fromMap(item);
    if (message != null) {
      messages.add(message);
    }
  }
  return messages;
}

bool _deepEquals(Object? a, Object? b) {
  if (a is Map && b is Map) {
    if (a.length != b.length) {
      return false;
    }
    for (final key in a.keys) {
      if (!b.containsKey(key) || !_deepEquals(a[key], b[key])) {
        return false;
      }
    }
    return true;
  }
  if (a is List && b is List) {
    if (a.length != b.length) {
      return false;
    }
    for (var i = 0; i < a.length; i++) {
      if (!_deepEquals(a[i], b[i])) {
        return false;
      }
    }
    return true;
  }
  return a == b;
}

  _ => '$value',
};
```

```dart
enum PayloadKind {
  hs1Ik(0x01),
  hs1IkPsk2(0x02),
  hs2(0x03),
  transport(0x04);

  const PayloadKind(this.wire);
  final int wire;

  /// Throws [FrameFormatException] for an unknown kind byte.
  static PayloadKind fromWire(int wire) {
    for (final kind in values) {
      if (kind.wire == wire) {
        return kind;
      }
    }
    throw FrameFormatException('Unknown payload kind $wire');
  }
}

final class ChannelPayload {
  ChannelPayload(this.kind, this.noiseMessage);

  final PayloadKind kind;
  final Uint8List noiseMessage;

    [kind.wire],
    noiseMessage,
  ]);

  /// Throws [FrameFormatException] for an empty payload or unknown kind.
  static ChannelPayload decode(Uint8List bytes) {
    if (bytes.isEmpty) {
      throw const FrameFormatException('Empty channel payload');
    }
    return ChannelPayload(
      PayloadKind.fromWire(bytes[0]),
      Uint8List.fromList(Uint8List.sublistView(bytes, 1)),
    );
  }
```

```dart
import '../noise/handshake.dart';
import '../noise/primitives.dart' show tagLen;
import '../protocol/messages.dart';
import '../relay/frames.dart';
import 'payload.dart';

/// Maximum `data` bytes in one `output` or `input` message.
const int kMaxOutputChunk = 16 * 1024;

/// Largest CBOR batch that still fits one relay frame:
/// 65536 - 26 (DATA header) - 1 (kind byte) - 16 (Poly1305 tag) = 65493.
const int kMaxSealedBatchBytes =
    kMaxFrameBytes - kDataFrameHeaderBytes - 1 - tagLen;

/// Encrypts/decrypts batches of [AppMessage] with an established transport.
final class SecureChannel {
  SecureChannel(NoiseTransport transport) : _transport = transport;

  final NoiseTransport _transport;

  /// Returns `ChannelPayload(PayloadKind.transport, ciphertext).encode()`,
  /// ready to be the payload of a [DataFrame]. Throws [ArgumentError] if
  /// the encoded batch is larger than [kMaxSealedBatchBytes]; split it.
  /// Results complete in call order (see [NoiseTransport]).
  Future<Uint8List> seal(List<AppMessage> messages) async {
    final plaintext = encodeBatch(messages);
    if (plaintext.length > kMaxSealedBatchBytes) {
      throw ArgumentError.value(
        plaintext.length,
        'messages',
        'batch exceeds $kMaxSealedBatchBytes bytes',
      );
    }
    final ciphertext = await _transport.encrypt(plaintext);
    return ChannelPayload(PayloadKind.transport, ciphertext).encode();
  }

  /// [noiseMessage] is `ChannelPayload.noiseMessage` of a TRANSPORT payload.
  /// Throws [NoiseException] if decryption fails and [FormatException] if
  /// the plaintext is not a valid batch. Either way the channel must be
  /// dropped and a new handshake started.
  Future<List<AppMessage>> open(Uint8List noiseMessage) async {
    final plaintext = await _transport.decrypt(noiseMessage);
    return decodeBatch(plaintext);
  }
}
```

```dart
import 'dart:typed_data';

import '../util/bytes.dart';

/// QR content: `shellx://pair?v=1&d=<uuid>&k=<base64url 32 bytes>&s=<base64url 32 bytes>`.
final class PairingUri {
  /// Throws [ArgumentError] if the key or secret is not 32 bytes or the
  /// device id is not a UUID.
  PairingUri({
    required this.agentDeviceId,
    required this.agentPublicKey,
    required this.secret,
  }) {
    try {
      uuidToBytes(agentDeviceId);
    } on FormatException {
      throw ArgumentError.value(
        agentDeviceId,
        'agentDeviceId',
        'must be a UUID',
      );
    }
    if (agentPublicKey.length != 32 || secret.length != 32) {
      throw ArgumentError('Pairing key and secret must be 32 bytes');
    }
  }

  static const String scheme = 'shellx';
  static const String host = 'pair';
  static const String version = '1';

  final String agentDeviceId;
  final Uint8List agentPublicKey;
  final Uint8List secret;

  String toUriString() =>
      '$scheme://$host?v=$version'
      '&d=$agentDeviceId'
      '&k=${base64UrlNoPad(agentPublicKey)}'
      '&s=${base64UrlNoPad(secret)}';

  /// Throws [FormatException] unless [input] is a version 1 ShellX pairing
  /// URI with a UUID `d` and 32-byte `k` and `s`. Surrounding whitespace is
  /// ignored; the device id is returned lowercase.
  static PairingUri parse(String input) {
    final Uri uri;
    try {
      uri = Uri.parse(input.trim());
    } on FormatException {
      throw FormatException('Not a ShellX pairing code', input);
    }
    if (uri.scheme != scheme ||
        uri.host != host ||
        (uri.path != '' && uri.path != '/')) {
      throw FormatException('Not a ShellX pairing code', input);
    }
    final query = uri.queryParameters;
    if (query['v'] != version) {
      throw FormatException('Unsupported pairing code version', query['v']);
    }
    final deviceId = query['d'];
    if (deviceId == null) {
      throw const FormatException('Pairing code without device id');
    }
    uuidToBytes(deviceId);
    final key = _decode32(query['k'], 'k');
    final secret = _decode32(query['s'], 's');
    return PairingUri(
      agentDeviceId: deviceId.toLowerCase(),
      agentPublicKey: key,
      secret: secret,
    );
  }

  static Uint8List _decode32(String? value, String name) {
    if (value == null) {
      throw FormatException('Pairing code without "$name"');
    }
    final bytes = fromBase64UrlNoPad(value);
    if (bytes.length != 32) {
      throw FormatException('Pairing code "$name" must be 32 bytes', value);
    }
    return bytes;
  }
}
```

```dart
/// String key-value storage. Apps back it with flutter_secure_storage.
abstract interface class KeyValueStore {
  Future<String?> read(String key);
  Future<void> write(String key, String value);
  Future<void> delete(String key);
}

/// Map-backed store for tests and headless (E2E) runs.
final class InMemoryKeyValueStore implements KeyValueStore {
  InMemoryKeyValueStore([Map<String, String>? initial])
    : values = {...?initial};

  /// Current contents; tests may inspect or seed it directly.
  final Map<String, String> values;

  @override
  Future<String?> read(String key) async => values[key];

  @override
  Future<void> write(String key, String value) async {
    values[key] = value;
  }
```

```dart
import '../noise/noise_key_pair.dart';
import '../storage/key_value_store.dart';
import '../util/bytes.dart';

abstract final class DeviceIdentity {
  /// Storage key of the base64url (no padding) X25519 private key.
  static const String storageKey = 'device_private_key';

  static final Expando<Future<NoiseKeyPair>> _inFlight = Expando();

  /// Returns the device's static key pair, creating and storing it on first
  /// use. Idempotent: later calls (and concurrent calls on the same [store])
  /// return the same key. A stored value that is not a 32-byte base64url key
  /// is replaced by a new key (the device must then pair again).
  static Future<NoiseKeyPair> loadOrCreate(KeyValueStore store) {
    final pending = _inFlight[store];
    if (pending != null) {
      return pending;
    }
    final future = _loadOrCreate(store);
    _inFlight[store] = future;
    return future.whenComplete(() => _inFlight[store] = null);
  }

  static Future<NoiseKeyPair> _loadOrCreate(KeyValueStore store) async {
    final stored = await store.read(storageKey);
    final existing = stored == null ? null : _decode(stored);
    if (existing != null) {
      return NoiseKeyPair.fromPrivateKey(existing);
    }
    final created = await NoiseKeyPair.generate();
    await store.write(storageKey, base64UrlNoPad(created.privateKey));
    return created;
  }

  static Uint8List? _decode(String stored) {
    try {
      final bytes = fromBase64UrlNoPad(stored);
      return bytes.length == 32 ? bytes : null;
    } on FormatException {
      return null;
    }
  }
}
```

```dart
/// Compares two semantic versions (`x.y.z`, optional `-prerelease`,
/// optional `+build` which is ignored). Returns a negative number, zero or a
/// positive number. Throws [FormatException] for anything else.
int compareVersions(String a, String b) {
  final left = _parse(a);
  final right = _parse(b);
  for (var i = 0; i < 3; i++) {
    final diff = left.core[i].compareTo(right.core[i]);
    if (diff != 0) {
      return diff;
    }
  }
  return _comparePrerelease(left.prerelease, right.prerelease);
}

final class _Version {
  _Version(this.core, this.prerelease);
  final List<int> core;
  final List<String> prerelease;
}

_Version _parse(String input) {
  final match = _semver.firstMatch(input.trim());
  if (match == null) {
    throw FormatException('Not a semantic version', input);
  }
  return _Version([
    int.parse(match[1]!),
    int.parse(match[2]!),
    int.parse(match[3]!),
  ], match[4]?.split('.') ?? const []);
}

int _comparePrerelease(List<String> a, List<String> b) {
  if (a.isEmpty || b.isEmpty) {
    // A release is greater than any pre-release of the same core version.
    return (a.isEmpty ? 1 : 0) - (b.isEmpty ? 1 : 0);
  }
  for (var i = 0; i < a.length && i < b.length; i++) {
    final x = int.tryParse(a[i]);
    final y = int.tryParse(b[i]);
    final int diff;
    if (x != null && y != null) {
      diff = x.compareTo(y);
    } else if (x != null) {
      diff = -1; // numeric identifiers sort before alphanumeric ones
    } else if (y != null) {
      diff = 1;
    } else {
      diff = a[i].compareTo(b[i]);
    }
    if (diff != 0) {
      return diff;
    }
  }
  return a.length.compareTo(b.length);
}
```

```dart
/// Minimal WebSocket surface used by [RelayConnection]; faked in tests.
abstract interface class RelaySocket {
  /// [String] for text frames, [Uint8List] for binary frames.
  Stream<Object> get messages;
  void sendText(String text);
  void sendBytes(Uint8List bytes);
  Future<void> close([int? code, String? reason]);

  /// Close code received from the server; set once [messages] is done.
  int? get closeCode;
}

typedef RelaySocketConnector =
    Future<RelaySocket> Function(Uri uri, Map<String, String> headers);

/// Connects with `dart:io` [WebSocket]. A rejected upgrade (for example
/// HTTP 401 for a bad token) throws [WebSocketException] whose
/// `httpStatusCode` is the HTTP status.
Future<RelaySocket> ioRelaySocketConnector(
  Uri uri,
  Map<String, String> headers,
) async {
  final socket = await WebSocket.connect(uri.toString(), headers: headers);
  return _IoRelaySocket(socket);
}

final class _IoRelaySocket implements RelaySocket {
  _IoRelaySocket(this._socket);

  final WebSocket _socket;

  @override
  late final Stream<Object> messages = _socket.map<Object>(
    (event) => switch (event) {
      String text => text,
      Uint8List bytes => bytes,
      List<int> bytes => Uint8List.fromList(bytes),
      _ => throw StateError('Unexpected WebSocket event ${event.runtimeType}'),
    },
  );

  @override
  void sendText(String text) => _socket.add(text);

  @override
  void sendBytes(Uint8List bytes) => _socket.add(bytes);

  @override
  Future<void> close([int? code, String? reason]) =>
      _socket.close(code, reason);

  @override
  int? get closeCode => _socket.closeCode;
}

/// Exponential backoff with "equal jitter".
final class Backoff {
  Backoff({
    Duration initial = const Duration(seconds: 1),
    Duration max = const Duration(seconds: 30),
    Random? random,
  }) : _initialMs = initial.inMilliseconds,
       _maxMs = max.inMilliseconds,
       _random = random ?? Random();

  final int _initialMs;
  final int _maxMs;
  final Random _random;
  int _attempt = 0;

  /// base = min(max, initial * 2^attempt); returns base/2 + random(0..base/2).
  Duration next() {
    final base = min(_maxMs, _initialMs * (1 << min(_attempt, 30)));
    _attempt++;
    final half = base ~/ 2;
    return Duration(milliseconds: base - half + _random.nextInt(half + 1));
  }

  void reset() {
    _attempt = 0;
  }
}
```

```dart
/// Minimal WebSocket surface used by [RelayConnection]; faked in tests.
abstract interface class RelaySocket {
  /// [String] for text frames, [Uint8List] for binary frames.
  Stream<Object> get messages;
  void sendText(String text);
  void sendBytes(Uint8List bytes);
  Future<void> close([int? code, String? reason]);

  /// Close code received from the server; set once [messages] is done.
  int? get closeCode;
}

typedef RelaySocketConnector =
    Future<RelaySocket> Function(Uri uri, Map<String, String> headers);

/// Connects with `dart:io` [WebSocket]. A rejected upgrade (for example
/// HTTP 401 for a bad token) throws [WebSocketException] whose
/// `httpStatusCode` is the HTTP status.
Future<RelaySocket> ioRelaySocketConnector(
  Uri uri,
  Map<String, String> headers,
) async {
  final socket = await WebSocket.connect(uri.toString(), headers: headers);
  return _IoRelaySocket(socket);
}

final class _IoRelaySocket implements RelaySocket {
  _IoRelaySocket(this._socket);

  final WebSocket _socket;

  @override
  late final Stream<Object> messages = _socket.map<Object>(
    (event) => switch (event) {
      String text => text,
      Uint8List bytes => bytes,
      List<int> bytes => Uint8List.fromList(bytes),
      _ => throw StateError('Unexpected WebSocket event ${event.runtimeType}'),
    },
  );

  @override
  void sendText(String text) => _socket.add(text);

  @override
  void sendBytes(Uint8List bytes) => _socket.add(bytes);

  @override
  Future<void> close([int? code, String? reason]) =>
      _socket.close(code, reason);

  @override
  int? get closeCode => _socket.closeCode;
}

/// Exponential backoff with "equal jitter".
final class Backoff {
  Backoff({
    Duration initial = const Duration(seconds: 1),
    Duration max = const Duration(seconds: 30),
    Random? random,
  }) : _initialMs = initial.inMilliseconds,
       _maxMs = max.inMilliseconds,
       _random = random ?? Random();

  final int _initialMs;
  final int _maxMs;
  final Random _random;
  int _attempt = 0;

  /// base = min(max, initial * 2^attempt); returns base/2 + random(0..base/2).
  Duration next() {
    final base = min(_maxMs, _initialMs * (1 << min(_attempt, 30)));
    _attempt++;
    final half = base ~/ 2;
    return Duration(milliseconds: base - half + _random.nextInt(half + 1));
  }

  void reset() {
    _attempt = 0;
  }
}

enum RelayConnectionState {
  disconnected,
  connecting,
  connected,
  revoked,
  replaced,
  stopped,
}

/// One reconnecting WebSocket to the relay hub (spec sections 6.1, 12).
///
/// * Sends text `ping` right after connecting and then every [pingInterval];
///   if no `pong` arrives within [pongTimeout] the socket is dropped and a
///   reconnect is scheduled.
/// * Close code 4002 -> [RelayConnectionState.revoked], 4001 ->
///   [RelayConnectionState.replaced]; neither reconnects. A rejected upgrade
///   with HTTP 401, or a null token, is treated as revoked too.
/// * Any other close, error, connect failure or connect attempt that takes
///   longer than 15 seconds -> [RelayConnectionState.disconnected] and a
///   reconnect after [Backoff.next]. The backoff resets when a `pong` is
///   received, so a relay that accepts and immediately drops us is not
///   hammered.
/// * Binary frames that fail [RelayFrame.decode] are dropped silently.
final class RelayConnection {
  RelayConnection({
    required Uri wsUri,
    required String? Function() token,
    RelaySocketConnector connector = ioRelaySocketConnector,
    Backoff? backoff,
    Duration pingInterval = const Duration(seconds: 30),
    Duration pongTimeout = const Duration(seconds: 10),
  }) : _wsUri = wsUri,
       _token = token,
       _connector = connector,
       _backoff = backoff ?? Backoff(),
       _pingInterval = pingInterval,
       _pongTimeout = pongTimeout;

  static const Duration connectTimeout = Duration(seconds: 15);

  final Uri _wsUri;
  final String? Function() _token;
  final RelaySocketConnector _connector;
  final Backoff _backoff;
  final Duration _pingInterval;
  final Duration _pongTimeout;

  final StreamController<RelayConnectionState> _states =
      StreamController.broadcast();
  final StreamController<RelayFrame> _frames = StreamController.broadcast();

  RelayConnectionState _state = RelayConnectionState.disconnected;
  RelaySocket? _socket;
  StreamSubscription<Object>? _subscription;
  Timer? _pingTimer;
  Timer? _pongTimer;
  Timer? _reconnectTimer;

  /// Incremented whenever the current attempt/socket is abandoned, so late
  /// callbacks from an old socket are ignored.
  int _generation = 0;

  RelayConnectionState get state => _state;
  Stream<RelayConnectionState> get states => _states.stream;
  Stream<RelayFrame> get frames => _frames.stream;

  /// Starts connecting. No-op while connecting or connected. May be called
  /// again after [stop], revoked or replaced (for example after a new login).
  void start() {
    if (_state == RelayConnectionState.connecting ||
        _state == RelayConnectionState.connected) {
      return;
    }
    _backoff.reset();
    unawaited(_connect());
  }

  /// Disconnects for good (until [start] is called again).
  Future<void> stop() async {
    if (_state == RelayConnectionState.stopped) {
      return;
    }
    final socket = _abandonSocket();
    _reconnectTimer?.cancel();
    _reconnectTimer = null;
    _setState(RelayConnectionState.stopped);
    if (socket != null) {
      await _closeQuietly(socket, 1000);
    }
  }

  /// Sends a frame; false (nothing sent) unless connected.
  bool send(RelayFrame frame) {
    final socket = _socket;
    if (_state != RelayConnectionState.connected || socket == null) {
      return false;
    }
    try {
      socket.sendBytes(frame.encode());
      return true;
    } on Object {
      return false;
    }
  }

  /// Skips the pending backoff delay (mobile returning to the foreground).
  /// Only acts while disconnected.
  void reconnectNow() {
    if (_state != RelayConnectionState.disconnected) {
      return;
    }
    _reconnectTimer?.cancel();
    _reconnectTimer = null;
    unawaited(_connect());
  }

  Future<void> _connect() async {
    _reconnectTimer?.cancel();
    _reconnectTimer = null;
    final generation = ++_generation;
    final token = _token();
    if (token == null) {
      _setState(RelayConnectionState.revoked);
      return;
    }
    _setState(RelayConnectionState.connecting);
    final pending = _connector(_wsUri, {'Authorization': 'Bearer $token'});
    final RelaySocket socket;
    try {
      socket = await pending.timeout(connectTimeout);
    } on Object catch (error) {
      if (error is TimeoutException) {
        unawaited(
          pending.then(
            (late) => _closeQuietly(late, 1000),
            onError: (Object _) {},
          ),
        );
      }
      if (generation != _generation) {
        return;
      }
      if (error is WebSocketException &&
          error.httpStatusCode == HttpStatus.unauthorized) {
        _setState(RelayConnectionState.revoked);
        return;
      }
      _scheduleReconnect();
      return;
    }
    if (generation != _generation) {
      await _closeQuietly(socket, 1000);
      return;
    }
    _socket = socket;
    _subscription = socket.messages.listen(
      (message) => _onMessage(generation, message),
      onError: (Object _) => _onClosed(generation, socket),
      onDone: () => _onClosed(generation, socket),
      cancelOnError: true,
    );
    _setState(RelayConnectionState.connected);
    _sendPing(generation);
    _pingTimer = Timer.periodic(_pingInterval, (_) => _sendPing(generation));
  }

  void _sendPing(int generation) {
    final socket = _socket;
    if (generation != _generation || socket == null) {
      return;
    }
    try {
      socket.sendText('ping');
    } on Object {
      _dropAndReconnect();
      return;
    }
    _pongTimer ??= Timer(_pongTimeout, () {
      if (generation == _generation) {
        _dropAndReconnect();
      }
    });
  }

  void _onMessage(int generation, Object message) {
    if (generation != _generation) {
      return;
    }
    if (message is String) {
      if (message == 'pong') {
        _pongTimer?.cancel();
        _pongTimer = null;
        _backoff.reset();
      }
      return;
    }
    if (message is Uint8List) {
      final RelayFrame frame;
      try {
        frame = RelayFrame.decode(message);
      } on FrameFormatException {
        return;
      }
      _frames.add(frame);
    }
  }

  void _onClosed(int generation, RelaySocket socket) {
    if (generation != _generation) {
      return;
    }
    _abandonSocket();
    switch (socket.closeCode) {
      case RelayCloseCode.revoked:
        _setState(RelayConnectionState.revoked);
      case RelayCloseCode.replaced:
        _setState(RelayConnectionState.replaced);
      default:
        _scheduleReconnect();
    }
  }

  void _dropAndReconnect() {
    final socket = _abandonSocket();
    if (socket != null) {
      unawaited(_closeQuietly(socket, 1000));
    }
    _scheduleReconnect();
  }

  void _scheduleReconnect() {
    _setState(RelayConnectionState.disconnected);
    _reconnectTimer?.cancel();
    _reconnectTimer = Timer(_backoff.next(), () => unawaited(_connect()));
  }

  /// Detaches from the current socket (if any) and invalidates callbacks.
  RelaySocket? _abandonSocket() {
    _generation++;
    _pingTimer?.cancel();
    _pingTimer = null;
    _pongTimer?.cancel();
    _pongTimer = null;
    unawaited(_subscription?.cancel());
    _subscription = null;
    final socket = _socket;
    _socket = null;
    return socket;
  }

  static Future<void> _closeQuietly(RelaySocket socket, int code) async {
    try {
      await socket.close(code);
    } on Object {
      // The socket is being discarded; errors while closing do not matter.
    }
  }

  void _setState(RelayConnectionState next) {
    if (_state == next) {
      return;
    }
    _state = next;
    _states.add(next);
  }
}
```
