# Git Graph Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A read-only Git Graph of the focused terminal's local repo, shown as a "Git" tab in the right sidebar and openable as a workspace tab.

**Architecture:** A new `History/` module in the `CmuxGit` package runs read-only git commands off the main thread and parses them into Codable values. A new `git-graph` surface in the `webviews/` React app draws them with `@tomplum/react-git-log`. App-side Swift (`Sources/GitGraph/`) hosts that page in a `WKWebView`, answers its requests over a reply-capable script message handler, follows the focused terminal's repo, refreshes on `.git` changes, and opens commit-file diffs through the existing diff viewer CLI.

**Tech Stack:** Swift 6.0 (SwiftPM `CmuxGit`, app target `cmux`), XCTest app tests and Swift Testing package tests, React 19 + Vite + bun test (`webviews/`), `@tomplum/react-git-log` 3.5.1, WebKit.

**Spec:** `docs/superpowers/specs/2026-10-26-git-graph-design.md` (Vietnamese). Mockup and spike screenshots: `docs/superpowers/design/2026-10-26-git-graph/`.

**Branch:** create `feat/git-graph` from `develop` before Task 1. Commit after every task.

## Deviations from the spec (decided while planning)

- **Tab position.** Declare `RightSidebarMode.git` after `.machines`, so the Git tab is appended at the end of the mode bar instead of after Files/Find. The bar's `ctrl+1…9` defaults follow the visible tab order (`RightSidebarMode.positionalDigit`). Inserting Git third would silently move every existing user's `ctrl+3` from Vault to Git. Users can drag the tab earlier in settings.
- **No router route.** The new page is picked by `data-cmux-webview-kind="git-graph"` in `webviews/src/main.tsx`, the same way agent-session is. It needs no TanStack route, so `verify:tanstack-router` is unaffected.
- **No `ShortcutAction`.** `.git` has `shortcutAction == nil`, like `.customSidebar`. The "Show Git Graph" palette command is added as a special case instead (Task 5).

## Global Constraints

- App-linked Swift must stay Swift 6.0 compatible. `CmuxGit` builds in Swift 6 language mode with `ExistentialAny` and `InternalImportsByDefault`.
- Git is read-only. Allowed subcommands: `log`, `for-each-ref`, `rev-parse`, `symbolic-ref`, `diff-tree`, `diff`, `status`, `hash-object` (only `-t tree --stdin` with empty input). Never `fetch`, `pull`, `checkout` or anything that writes.
- Run every git command through `SystemWorkspaceChangesGitRunner`. It strips `GIT_DIR`, `GIT_WORK_TREE` and `GIT_CONFIG*` and sets `GIT_OPTIONAL_LOCKS=0`.
- Every git command also passes `-c core.fsmonitor=false -c log.showSignature=false -c color.ui=false` before the subcommand. Every `diff`/`diff-tree -p` passes `--no-ext-diff --no-textconv`. Reason: repo config must not be able to run programs.
- Values from the page are untrusted:
  - a sha must match `^[0-9a-f]{40}$|^[0-9a-f]{64}$`;
  - a path must be a `path` or `oldPath` from `fileChanges` of that same sha;
  - a branch filter must be the `fullName` of a ref returned by `refs`;
  - `skip` must be within `0...5000`.
- Git arguments are an argv array, never a shell string. Revisions come before a literal `--`; paths come after it.
- Commit messages and ref names are rendered as React text. No `dangerouslySetInnerHTML` anywhere under `webviews/src/git-graph/`.
- Paging: page size **300**; maximum loaded commits **5,000**. Then show the `limitReached` label.
- Search covers only loaded commits. It highlights matches and never hides rows.
- Lane colours, in order: `#60a5fa`, `#c4b5fd`, `#6fd49a`, `#e8c468`, `#7dd3fc`, `#a5b4fc`, `#e88a8a`, `#99f6e4`. Pass them to react-git-log as `rgb(r, g, b)` strings, because hex renders invisible in dark mode.
- Ref chip colours: local branch outline `#60a5fa`; checked-out branch solid `#93c5fd` with text `#0b0716`; remote outline `#c4b5fd`; tag outline `#e8c468`. No gradients, no glow.
- Narrow layout below **560 px** page width; wide layout at 560 px and above.
- The page loads only bundled files (`loadFileURL` under `Bundle.main.resourceURL`). Every navigation other than the trusted shell URL and in-page fragments is cancelled.
- Every new user-facing string goes in `Resources/Localizable.xcstrings` with `en, de, fr, ar, es, zh-Hant, zh-Hans, ko, ja, vi`. Avoid count-dependent sentences: write "Files changed: {count}", not "{count} files changed". Check with `python3 scripts/localization_catalog.py check`. `./scripts/localize-changes` is broken in this fork because `web/i18n/routing.ts` is missing.
- Build and test only through repo scripts. Never use bare `xcodebuild` or an untagged `cmux DEV.app`.
  - App tests: `scripts/shellx/test-app.sh <Suite>`.
  - App build: `scripts/test-unit.sh build`.
  - Package tests: `swift test --package-path Packages/macOS/CmuxGit --filter <Name>`.
  - Webviews: `cd webviews && bun test <path>` and `bun run build`.
- Wire new app files with `python3 scripts/wire-app-sources.py <files>`. After adding or renaming a `cmuxTests/` file, run `./scripts/sync-test-wiring`.
- Never quit or relaunch the user's running ShellX/cmux app.

## Review Focus

1. **Hostile or odd commit text.** Subjects with `<img onerror=…>`, emoji, RTL text or 500+ characters must render as plain text without breaking the row. Tests: Task 1 (parser keeps such a subject intact in its own field) and Task 4 (no `dangerouslySetInnerHTML` anywhere in the surface).
2. **Ref names and bridge parameters as injection vectors.** Branch names with `/`, unicode or `-`-like shapes, and params such as `--output=/tmp/x` or `../../etc/passwd`, must be rejected before git runs. Test: Task 2, `rejectsUntrustedArguments`.
3. **Repos in unusual states.** Empty repo (no commits), detached HEAD, shallow clone (parents missing), linked worktree (`.git` is a file), paths with spaces/unicode/newlines, renames, binary files. Each must give a defined state, not an error page. Tests: Task 1 (paths, renames, binary) and Task 2 (empty, detached, shallow, worktree).
4. **Fast focus switching between repos.** A late reply for repo A must never paint over repo B. A refresh must keep the selected commit and the scroll position. Tests: Task 6 (generation stamping drops stale replies) and Task 3 (`mergePage` keeps the selection).
5. **Big or slow repos.** The 5,000 cap must hold. Git timeout, oversized output and missing git must each map to a state with a Retry button. Tests: Task 2 (cap with an injected small limit, timeout mapping) and Task 6 (error state reply).

**Interfaces:**
- Produces (all `public`, `Sendable`, `Equatable`, `Codable`):
  - `GitHistoryCommit { sha: String; parents: [String]; source: String; authorName: String; authorEmail: String; authorDate: String; committerDate: String; subject: String }`. Dates are strict ISO-8601 from `%aI`/`%cI`. `source` is the short ref name from `--source` (`%S`), with `refs/heads/`, `refs/remotes/` and `refs/tags/` stripped.
  - `enum GitHistoryRefKind: String { case localBranch, remoteBranch, tag }`
  - `GitHistoryRef { kind; name: String /* "main", "origin/main", "v1.0" */; fullName: String /* "refs/heads/main" */; target: String /* commit sha; annotated tags peeled */ }`
  - `GitHistoryHead { sha: String?; branch: String? /* nil when detached or unborn */ }`
  - `GitHistoryPage { commits: [GitHistoryCommit]; hasMore: Bool; reachedLimit: Bool }`
  - `enum GitHistoryFileStatus: String { case added, modified, deleted, renamed, copied, typeChanged, unmerged, unknown }`
  - `GitHistoryFileChange { path: String; oldPath: String?; status: GitHistoryFileStatus; additions: Int?; deletions: Int? /* nil = binary */ }`
  - `GitHistoryWorkingTreeStatus { added: Int; modified: Int; deleted: Int; var isClean: Bool }`. Untracked files count as added.
  - `GitHistoryQuery { includeRemotes: Bool; branchFullName: String? }`, with a public memberwise init.
  - `enum GitHistoryLimits { static let pageSize = 300; static let maximumCommits = 5_000 }`
  - `enum GitHistoryError: Error, Equatable, Sendable { case notARepository, gitUnavailable, timedOut, outputTooLarge, invalidArgument(String), failed(exitCode: Int32) }`
- Produces (internal): `enum GitHistoryParser`:
  - `static let logFormat = "%H%x1f%P%x1f%S%x1f%an%x1f%ae%x1f%aI%x1f%cI%x1f%s%x1e"`
  - `static func commits(fromLog: Data) -> [GitHistoryCommit]`
  - `static let refFormat = "%(refname)%x1f%(objectname)%x1f%(*objectname)%x1e"`
  - `static func refs(fromForEachRef: Data) -> [GitHistoryRef]`. Skips `refs/remotes/*/HEAD`; uses `*objectname` when present.
  - `static func fileChanges(nameStatusZ: Data, numstatZ: Data) -> [GitHistoryFileChange]`. Parses `-z` output; numstat `-` means binary (nil); renames `R100` and copies `C75` carry `oldPath`.
  - `static func workingTreeStatus(porcelainV1Z: Data) -> GitHistoryWorkingTreeStatus`

**Interfaces:**
- Consumes: Task 1 types; `SystemWorkspaceChangesGitRunner` and `WorkspaceChangesGitRunning` (internal to CmuxGit).
- Produces: `public struct GitHistoryService: Sendable`
  - `public init()`
  - internal test init: `init(runner: any WorkspaceChangesGitRunning, pageSize: Int = GitHistoryLimits.pageSize, maximumCommits: Int = GitHistoryLimits.maximumCommits, wallTimeLimit: TimeInterval = 15)`
  - `public func head(repositoryRoot: String) async throws -> GitHistoryHead`
  - `public func refs(repositoryRoot: String) async throws -> [GitHistoryRef]`
  - `public func page(repositoryRoot: String, query: GitHistoryQuery, skip: Int) async throws -> GitHistoryPage`
  - `public func fileChanges(repositoryRoot: String, sha: String) async throws -> [GitHistoryFileChange]`
  - `public func filePatch(repositoryRoot: String, sha: String, path: String) async throws -> Data`
  - `public func workingTreeStatus(repositoryRoot: String) async throws -> GitHistoryWorkingTreeStatus`

Decisions the implementer cannot infer:
- **Off the main thread.** Blocking git runs on a dedicated concurrent `DispatchQueue` (label `pro.shellx.git-history`, qos `.utility`), using the same pattern as `WorkspaceChangesService.offCooperativePool`.
- **Common prefix.** Every invocation starts with `["-c","core.fsmonitor=false","-c","log.showSignature=false","-c","color.ui=false"]`.
- **`page`:** `log --date-order --source --format=<logFormat> --skip=<skip> --max-count=<n+1> <revisions> --`.
  - `n = min(pageSize, maximumCommits - skip)`.
  - `<revisions>` is `[branchFullName]` when a filter is set. Otherwise it is `--branches --tags HEAD`, plus `--remotes` when `includeRemotes` is true.
  - `hasMore` = more than `n` records came back.
  - `reachedLimit` = `skip + commits.count >= maximumCommits`.
  - When `head(...).sha == nil` (unborn repo), return an empty page without running `log`.
- **`head`:** `rev-parse -q --verify HEAD^{commit}`, where exit 1 means unborn, plus `symbolic-ref -q --short HEAD`, where exit 1 means detached.
- **`fileChanges`:** `diff-tree -r -M --no-commit-id -z --name-status` and the same call with `--numstat`.
  - Arguments are `<firstParent> <sha>` when the commit has parents, otherwise `--root <sha>`.
  - Read parents with `rev-list --parents -n 1 <sha>`.
  - Merges compare against the first parent only.
- **`filePatch`:** `diff --no-color --no-ext-diff --no-textconv -M <base> <sha> -- [oldPath] <path>`. `base` is the first parent; for a root commit it is the empty tree from `hash-object -t tree --stdin` with empty stdin, so it works for sha256 repos too.
- **`workingTreeStatus`:** `status --porcelain=v1 -z --untracked-files=normal`.
- **Error mapping.**
  - Run `rev-parse --show-toplevel` first; when it fails, throw `.notARepository`.
  - A missing git executable throws `.gitUnavailable`.
  - Wall-time expiry throws `.timedOut`.
  - `standardOutputWasTruncated` throws `.outputTooLarge`. Output caps: 16 MB for `page`, 8 MB for `filePatch`.
- **`GitHistoryArgumentValidator`** (internal) enforces the untrusted-input rules from Global Constraints. It throws `.invalidArgument(<field>)` before any git call.

### Task 3: Webviews Git Graph model (pure functions)

**Interfaces:**
- Produces, exported from `model.ts`:
  - `GIT_GRAPH_LANE_COLORS: readonly string[]`: the eight hex values from Global Constraints.
  - `toRgb(hex: string): string`. `"#60a5fa"` becomes `"rgb(96, 165, 250)"`.
  - `toLogEntries(commits: GitGraphCommit[]): GitLogEntry[]`. Maps `hash` = sha, `parents`, `branch` = `source`, `message` = subject, `committerDate`, `authorDate`, `author: {name, email}`. Parents outside the loaded set are kept; the library handles them, as the spike showed.
  - `type RefChip = { label: string; kind: "head" | "local" | "remote" | "tag" }`
  - `refChipsByCommit(refs: GitGraphRef[], head: GitGraphHead): Map<string, RefChip[]>`. Order within a commit: head, local, remote, tag; then by name.
  - `findMatches(commits: GitGraphCommit[], query: string): string[]`. Returns the shas of matching commits in list order. Matching is case-insensitive on subject, author name and author email, plus a sha prefix when the query is at least 4 hex characters. An empty or whitespace query returns `[]`.
  - `layoutFor(width: number): "narrow" | "wide"`. The breakpoint is 560.
  - `mergePage(existing: GitGraphCommit[], page: GitGraphPage, skip: number): GitGraphCommit[]`. With `skip === 0` the result is replaced; otherwise it is appended without duplicate shas.
  - `visibleChips(chips: RefChip[], layout): { shown: RefChip[]; overflow: number }`. In narrow layout it shows the first chip and returns the rest as an overflow count; in wide layout it shows all.
