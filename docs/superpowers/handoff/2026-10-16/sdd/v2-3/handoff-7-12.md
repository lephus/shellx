## What chunk 3 must know (deviations from the plan's text that later code builds on)

**Windows engine (Task 7, `lib/src/browser/engines/win_floating_engine.dart`)**
- An empty `dataFolder` starts no WebView2, so every call answers `LoadFailed(unavailable)` (F1).
- `UrlChanged` is emitted only for a URL with a scheme (it reuses `pageUriOf`).
- Once disposed, the engine makes no plugin call.
- The plugin's `onPageFinished` right after a failure is dropped, so a failed load never ends with `LoadFinished`. A 4xx/5xx page still finishes.
- `_ready` is a `Future<bool>` that never fails.
- `buildView()` mounts the plugin's widget only after a successful creation.
- **`dispose()` completes only after the engine's view has left the tree** (mount tracking). Never await it on a path where the view stays mounted. Task 10's `unawaited(engine.dispose())` is fine.
- **Task 13:** the plugin's `_resume` makes the WebView2 visible again on every mount or reactivation. A covered page (`setVisible(false)` while an overlay is open) must be covered again after a mount: re-apply `setVisible(false)`, or never remount while covered.

**Dock controller (Task 8, `lib/src/tools/tool_dock.dart`)**
- Once after it starts (a microtask from `build`), `ToolDockController` removes every registry tool whose workspace the sidebar lacks: the orphan prune, spec D2/§8.
- **Tests in Tasks 13–15 must add tools only to `kDefaultWorkspaceId` or to workspaces created through the sidebar (`createFor`).** Otherwise the tool silently disappears.
- In the app, the dock controller (and so the prune) starts at every launch: `main.dart:468` runs `RestorePersistence.start()`, which listens to `toolDockProvider` (Task 9).
- **R14 ruling for Tasks 13/14:** `TerminalTabs.select(sameId)` does not change `selectedId`, so re-selecting the tab that stayed selected under a "loose" workspace does not end loose. Every tab-selection gesture must call `toolDockProvider.notifier.clearLoose()`: sidebar tab tap, ⌘1…9, next/previous tab, palette. Add one test.

**Live pages (Task 10, `lib/src/tools/tool_page.dart`)**

- `stop()` (✕) ends the loading state.
- `reload()` (↻) loads the recovery URL while an explicit load is pending. `engine.reload()` is used only for a committed page with no error and nothing pending.
