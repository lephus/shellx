- `windows/installer/shellx-native.iss` (reduced from the Flutter script): new AppId (generate a fresh GUID once and hard-code it with the "never change it" comment), `AppName=ShellX 2`, `AppVersion=2.0.0`, `AppPublisher` as Flutter, `DefaultDirName={autopf}\ShellX Native`, `DefaultGroupName=ShellX 2`, `PrivilegesRequired=lowest`, `MinVersion=10.0.17763`, `ArchitecturesAllowed=x64compatible`, `ArchitecturesInstallIn64BitMode=x64compatible`, `OutputBaseFilename=ShellX-Setup-{#AppVersion}-sprint`, `UninstallDisplayIcon={app}\shellx-desktop.exe`, `SetupIconFile` = the app icon, languages Vietnamese (default) + English, files: `shellx-desktop.exe` (+ any DLLs CI staged), shortcuts `{autoprograms}\ShellX 2 (thử nghiệm)` and optional desktop icon same name; `[Run]` launch postinstall skipifsilent. No `taskkill` of anything except — if needed for upgrades — `shellx-desktop.exe` via the Restart Manager (`CloseApplications=yes` is fine; it only targets files being replaced). `[UninstallDelete]`: nothing outside `{app}` (user state `%LOCALAPPDATA%\ShellX\native` stays — document; the user can delete it).
- `windows/installer/Vietnamese.isl`: copied verbatim from `flutter-final:release/windows/Vietnamese.isl` (pinned to Inno Setup 6.7.1).
- `windows/installer/build-installer.ps1`: adapted (checks `shellx-desktop.exe`, installs Inno Setup 6.7.1 via choco when missing — same as Flutter's pipeline, `/DAppVersion /DSourceDir /DOutputDir /DAppIcon`). No VC++ DLL requirement if the exe is statically linked (below).
- Static CRT so a clean PC needs no VC++ redistributable: `windows/.cargo/config.toml` with `[target.x86_64-pc-windows-msvc] rustflags = ["-C", "target-feature=+crt-static"]` — verify the `app` job's dumpbin dependents no longer list `VCRUNTIME140.dll`/`MSVCP140.dll` (libghostty-vt is built by Zig; if its static lib forces the dynamic CRT and the link fails, revert to shipping the three DLLs from the VS install like Flutter's pipeline and say so).
- `windows/installer/check_coexistence.py` (stdlib only): parses `shellx-native.iss` (resolve `#define`s used in the keys checked) and asserts against the Flutter constants above (hard-coded in the script with a comment naming `flutter-final`): AppId differs, AppName differs, exe ≠ `ShellX.exe` (case-insensitive), DefaultDirName differs, group and every shortcut name differ, no line runs `taskkill` on `ShellX.exe` or `shellx-mux.exe`, no `[InstallDelete]`/`[UninstallDelete]` entry touches `{userappdata}\pro.shellx` or `{localappdata}\ShellX\` except `{localappdata}\ShellX\native` (and preferably none at all). Unit-test it with `python3 -m unittest` (test file `windows/installer/test_check_coexistence.py`: the real .iss passes as `installer_coexists_with_flutter`; a doctored copy with the Flutter AppId fails; one with `taskkill /IM "ShellX.exe"` fails). Runs on the Mac.
