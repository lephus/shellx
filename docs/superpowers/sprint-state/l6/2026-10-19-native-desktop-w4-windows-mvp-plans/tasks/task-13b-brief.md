You must not edit `remote_session.rs` / `remote_link.rs` except for a bug that blocks you (then say so in the report).

## Goal
Windows user clicks "Mở" on an online Mac that has granted access (sidebar row action `RowAction::Open`, or the pairing panel's "Mở" button after approval) → a new tab (or the focused tab, per existing sidebar semantics in Task 7/8) shows that Mac's terminal over relay v2; typing, IME, paste, selection, resize, split, close, reconnect all work like a local pane, with the input gating and status pill the brief describes.

## Required (UI, `cfg(windows)` modules compile on CI only)
1. `ui/root.rs` / `ui/panes.rs` / `ui/term_view.rs` (+ `ui/sidebar.rs`, `ui/pairing.rs`): `RowAction::Open` and the pairing panel's "Mở" (currently disabled with tooltip `Str::ComingSoon`) open a remote tab: one `RemoteSession` per `machine_id` shared by all of that Mac's panes (create on first Open, reuse while `!status().finished`, otherwise start a new one), `PaneTarget::Remote{machine_id, terminal_id}` in the model; `Retargeted{terminal_id}` updates the stored target; `Applied::Ended` closes only that pane through the existing last-pane-respawn path (Review Focus 4: a remote terminal ending must never quit the app or leave an empty window); closing a remote pane calls `session.close_pane(id)`.
2. A remote `TermView` is backed by `RemoteMirror` (its `TermCore` is REPLACED on a snapshot reset — never cache a `TermCore` handle across frames; read `mirror.core()` per frame/paint). Local and remote panes share rendering, selection, copy, bracketed paste (`encode_paste`), IME placement (Task 9), mouse selection; they differ only in the byte link. Keyboard text/chords/paste go through the gated `RemoteLink` (input refused while not attached, never queued). IME commits while not attached are dropped and `Str::InputPaused` is flashed (existing status-flash mechanism of the window/pane; add one if none exists). Review Focus 1: composed Telex text leaves as ONE write of the committed UTF-8 (no per-keystroke preedit bytes).
3. Overlay pill centered on a remote pane while `session.status().phase != Connected` or an error is set: RAISE bg, BORDER border, no gradient/shadow glow; text `Str::Connecting` / `Str::Reconnecting` (RUNNING dot) / `Str::Offline` (MUTED) / `Str::RemoteEnded`, plus `status.attach_error` and `status.error` (FingerprintMismatch, NeedsPairing → new `Str` keys in `shellx-model/src/strings.rs`, vi + en, Vietnamese default, e.g. "Khóa của máy không khớp, không kết nối" / "Cần xin quyền truy cập lại"; keep the string-count test and `SHELL_STRINGS` in `shell_info.rs` in sync, run `--smoke-ui-assets` logic on the Mac). `status.save_error` is shown in the pill's detail line when set. The UI thread only reads `status()` snapshots; sinks send `PaneEvent`s over an `async_channel`, one UI task per pane.
4. Split of a remote pane (existing split commands) → `Want::New` on the same machine's session (spec §8.6 C12: the new shell runs on the Mac) → new remote pane; a split of a local pane stays local. New tab command (Ctrl+Shift+T) stays local.
5. The 15 s machine list refresh (Task 10b account/machines flow already polls `machines.list`): feed `session.set_machine_online(online)` for open sessions. Pass `SessionConfig.invite_dir = paths::core_dir()?.join("tickets")`, `links: Some(LinksStore::default_location()?)`, `state_dir = paths::remote_dir()?`, `device_name = os_info::device_name()`, `connector = Arc::new(RelayConnector)`, the shared `Arc<dyn CoreCall>` (the same configured core the account flow uses; it must be callable from worker threads — if it is not `Send + Sync` or is serialized behind the account worker, report and propose the smallest adapter). After an enrollment save (`enrolled = true`, invite removed) reload `links.json` in the UI through `Cmd::LoadLinks` (see `task-12b-report.md`); the UI caches links.
6. Sign-out / account change: close all remote sessions (`session.close()`), remote tabs become closed panes via the normal path.
7. Window title / a11y stopgap (Task 15): remote focused pane writes the title the same way a local one does.
8. No telemetry, no hard-coded relay URL (R17); no gradients; Vietnamese strings.
